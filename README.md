## Features

### 1. Post a Gig

Creators can publish:

- Creator name
- Gig title
- Category
- Rate
- Description

### 2. Browse & Search

Clients can:

- Browse all gigs
- Search by creator, title, category or description
- Filter by category
- Sort by newest
- Sort by price

Newest-first is the default discovery method.

### 3. Book a Gig

Clients can:

- Open a gig
- Enter their name
- Enter their email
- Add an optional message
- Submit a booking request
- Receive a confirmation

### 4. Creator Dashboard

Creators can:

- See incoming bookings
- See client details
- Accept requests
- Decline requests
- View pending and accepted bookings

### 5. My Bookings

Clients can see:

- Pending bookings
- Accepted bookings
- Declined bookings

Declined bookings remain visible in booking history.
